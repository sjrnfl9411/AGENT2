# 이메일 시퀀스 (Email Sequences)

웰컴/온보딩 시퀀스, 리드 너처링, 재참여(win-back), 라이프사이클 이메일 등 여러 통으로 구성된
자동화 이메일 플로우를 설계할 때 적용합니다. (콜드 아웃바운드는 `cold-email` 스킬, 인앱 온보딩은
이 스킬 범위 밖 — 일반 원칙으로 대응)

## 설계 전 파악할 것

1. **시퀀스 유형**: 웰컴/온보딩, 리드 너처, 재참여, 구매 후, 이벤트 기반, 교육형, 세일즈
2. **오디언스 맥락**: 누구인가? 무엇이 이 시퀀스에 들어오게 했는가? 이미 무엇을 알고/믿고 있는가?
   현재 관계 단계는?
3. **목표**: 주 전환 목표, 관계 구축 목표, 세그멘테이션 목표, 성공의 정의

## 핵심 원칙

1. **이메일 하나 = 목적 하나**: 각 이메일은 하나의 주 목적, 하나의 주 CTA만 가짐
2. **요청 전에 가치**: 유용함으로 먼저 다가가 신뢰를 쌓고, 팔 권리를 얻으세요
3. **양보다 관련성**: 적고 좋은 이메일이 이깁니다. 세그먼트로 관련성을 높이세요
4. **명확한 다음 경로**: 모든 이메일은 독자를 어딘가로 이동시켜야 하며, 링크는 유용한 일을 해야 함

## 시퀀스 전략

**길이**: 웰컴 3-7통 / 리드 너처 5-10통 / 온보딩 5-10통 / 재참여 3-5통 (세일즈 사이클 길이, 제품
복잡도, 관계 단계에 따라 조정)

**타이밍**: 웰컴 이메일은 즉시, 초반은 1-2일 간격, 너처는 2-4일 간격, 장기는 주 1회~격주. B2B는
주말 피하기, B2C는 주말 테스트, 시간대는 로컬 타임 기준.

**제목**: 명확 > 영리, 구체적 > 모호, 혜택 또는 호기심 기반, 40-60자가 이상적, 이모지는 테스트해볼 것
(호불호가 갈림)
- 패턴: 질문형("아직도 X로 고생 중이세요?"), 하우투("[기간] 안에 [결과]를 얻는 법"), 숫자형
  ("[혜택]하는 3가지 방법"), 직접형("[이름]님, [것]이 준비됐어요"), 스토리 티저("[주제]에서 저지른 실수")

**프리뷰 텍스트**: 제목을 확장, ~90-140자, 제목 반복하지 말고 생각을 완결하거나 궁금증 추가

## 시퀀스 유형별 개요

- **웰컴 시퀀스** (가입 직후): 5-7통, 12-14일. 웰컴+가치전달(즉시) → 퀵윈(1-2일) → 스토리/이유(3-4일) →
  소셜프루프(5-6일) → 반론극복(7-8일) → 핵심기능(9-11일) → 전환(12-14일)
- **리드 너처 시퀀스** (구매 전): 6-8통, 2-3주. 리드마그넷 전달(즉시) → 주제확장 → 문제심화 →
  솔루션프레임워크 → 케이스스터디 → 차별화 → 반론처리 → 직접 오퍼
- **재참여 시퀀스**: 30-60일 비활성 트리거, 3-4통 2주. 안부확인(진심으로) → 가치상기(새 소식) →
  인센티브(특별 제안) → 마지막 기회(유지 또는 구독취소)
- **온보딩 시퀀스** (제품 사용자): 5-7통, 14일. 인앱 온보딩과 조율(중복 아닌 지원 역할). 웰컴+첫걸음 →
  시작 도움 → 기능 하이라이트 → 성공사례 → 체크인(7일) → 고급 팁 → 업그레이드/확장(14일+)

## 카테고리별 이메일 유형

- **온보딩**: 신규 유저 시리즈, 신규 고객 시리즈, 핵심 온보딩 단계 리마인더, 초대
- **리텐션**: 유료 전환, 상위 플랜 업그레이드, 리뷰 요청, 선제적 지원 제안, 사용량 리포트, NPS 설문,
  추천 프로그램
- **결제**: 연간 전환 유도, 결제 실패 복구, 취소 설문, 갱신 예정 알림
- **사용 현황**: 일/주/월간 요약, 핵심 이벤트 알림, 마일스톤 축하
- **윈백**: 만료된 트라이얼, 해지 고객
- **캠페인**: 월간 뉴스레터, 시즌 프로모션, 제품 업데이트, 업계 뉴스 요약, 가격 변경 안내

## 이메일 카피 가이드

**구조**: 훅(첫 줄이 주의를 끔) → 맥락(왜 중요한지) → 가치(유용한 내용) → CTA(다음 행동) →
사인오프(인간적이고 따뜻한 마무리)

**포맷팅**: 짧은 단락(1-3문장), 섹션 사이 여백, 스캔 가능한 불릿, 강조는 볼드로 아껴서, 모바일
우선(대부분 폰으로 읽음)

**톤**: 대화체(격식 아님), 1인칭(I/we)과 2인칭(you) 혼용, 능동태, 소리 내어 읽어서 사람같이 들리는지 확인

**길이**: 트랜잭셔널 50-125단어 / 교육형 150-300단어 / 스토리형 300-500단어

**CTA**: 주요 액션은 버튼, 보조 액션은 링크, 이메일당 하나의 명확한 주 CTA, 버튼 텍스트는
행동+결과

## 산출물 포맷

**시퀀스 개요**: 시퀀스명 / 트리거 / 목표 / 이메일 수 / 간격 / 이탈 조건

**각 이메일별**: 번호/이름(목적) / 발송시점 / 제목 / 프리뷰 텍스트 / 본문 전체 / CTA(버튼텍스트 →
링크대상) / 세그먼트·조건(해당 시)

**측정 계획**: 무엇을 측정할지와 벤치마크

## 관련 영역

- 콜드 아웃바운드 이메일 → `cold-email` 스킬
- 이메일이 링크하는 랜딩페이지 카피 → `copywriting` 스킬
- 이메일 요소 테스트 → `ab-testing` 스킬
- 이메일 캡처 팝업, 리드 마그넷, 라이프사이클 트리거 설계는 이 스킬 원칙을 준용해 대응
