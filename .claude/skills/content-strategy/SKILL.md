# 콘텐츠 전략 (Content Strategy)

무엇을 콘텐츠로 만들지 기획하고, 트래픽/리드/권위를 만드는 콘텐츠 계획을 세울 때 적용합니다.
개별 콘텐츠 "작성"이 아니라 "무엇을 만들지 결정"하는 작업입니다 (작성 자체는 `copywriting` 스킬 참고).

## 기획 전 파악할 것

1. **비즈니스 맥락**: 회사가 하는 일, 이상적 고객, 콘텐츠의 주 목표(트래픽/리드/브랜드 인지/
   업계 권위), 제품이 해결하는 문제
2. **고객 리서치**: 구매 전 고객이 묻는 질문, 세일즈 콜에서 나오는 반론, 지원 티켓에 반복되는 주제,
   고객이 문제를 표현하는 언어
3. **현재 상태**: 기존 콘텐츠와 성과, 가용 리소스(작가/예산/시간), 가능한 포맷(글/영상/오디오)
4. **경쟁 환경**: 주요 경쟁사, 시장의 콘텐츠 공백

## 콘텐츠를 제품처럼 다루기

각 콘텐츠는 하나의 "출시"입니다. 콘텐츠는 부가 비용이 아니라 **브랜드의 표면적(surface area)**
— 발행된 각 글은 낯선 사람이 우리를 발견하는 새 진입점이며, 수백 개가 쌓이면 24시간 일하는 수백
개의 문이 됩니다. 제품 출시와 같은 의도로 기획·제작·배포하세요. 쓰고 잊힌 글은 표면적이 거의
없고, 배포된 글("한 번 만들고 두 번 배포하기" 참고)은 그 표면적을 배가시킵니다.

## Searchable vs Shareable

모든 콘텐츠는 검색가능(searchable), 공유가능(shareable), 또는 둘 다여야 합니다. 검색 트래픽이
기반이므로 이 순서로 우선순위를 둡니다.

- **검색가능 콘텐츠**: 이미 존재하는 수요를 포착. 답을 찾는 사람들을 위해 최적화.
  - 특정 키워드/질문을 타겟, 검색 의도와 정확히 일치, 검색어와 맞는 명확한 제목, 검색 패턴을
    반영한 헤딩 구조, 제목/헤딩/첫 문단/URL에 키워드 배치, 포괄적으로 다루기(질문을 남기지 않기),
    데이터/예시/권위 있는 출처 링크 포함, AI/LLM 발견성 최적화(명확한 포지셔닝, 구조화된 콘텐츠)
- **공유가능 콘텐츠**: 수요를 새로 만듦. 아이디어를 퍼뜨리고 대화를 만듦.
  - 새로운 통찰/독점 데이터/반직관적 주장으로 시작, 근거 있는 논증으로 통념에 도전, 감정을 건드리는
    스토리, 똑똑해 보이거나 남을 돕고 싶어 공유하게 만드는 콘텐츠, 트렌드/신흥 문제와 연결,
    솔직한 경험 공유

## 콘텐츠 유형

**검색가능:**
- **유스케이스 콘텐츠**: [페르소나] + [유스케이스] 공식으로 롱테일 키워드 타겟 (예: "디자이너를 위한
  프로젝트 관리")
- **허브 앤 스포크**: 허브(포괄적 개요) + 스포크(관련 세부주제). 허브를 먼저 만들고 스포크로 확장,
  서로 전략적으로 내부 링크. 대부분의 콘텐츠는 `/blog` 하나로 충분하며, 여러 층위의 깊이가 있는
  대형 주제에만 전용 허브/스포크 URL 구조를 씁니다.
- **템플릿 라이브러리**: 구매 의도가 높은 키워드 + 제품 도입을 동시에 노림 (예: "마케팅 플랜 템플릿")

**공유가능:**
- **소트 리더십**: 모두가 느끼지만 이름 붙이지 못한 개념을 언어화, 근거로 통념에 도전
- **데이터 기반 콘텐츠**: 제품 데이터 분석(익명화), 공개 데이터 분석, 자체 리서치
- **전문가 라운드업**: 15-30명의 전문가가 한 질문에 답 — 배포가 내장되어 있음
- **케이스 스터디**: 문제 → 해결 → 결과 → 배운 점 구조
- **메타 콘텐츠**: 비하인드 신 투명성 콘텐츠 ("첫 5천 달러 MRR을 어떻게 만들었나" 등)

**백링크 획득 포맷** (B2B SaaS 대상 벤더 조사, 방향성 참고용): 통계/데이터 로드업 페이지가 페이지
비중 대비 백링크를 4.25배 더 받음 (원본 리서치 0.80배, 궁극 가이드 0.77배보다 훨씬 높음). 시사점:
(1) 카테고리 통계 페이지를 만들고 신선하게 유지하면 저비용으로 꾸준히 링크를 얻음(AI 인용에도 유리),
(2) 자체 리서치를 할 때는 결과를 인용하기 쉬운 한 줄 통계로 정리한 자체 로드업 페이지를 함께 만들어
그 리서치가 만드는 링크를 직접 확보하세요. 가이드/템플릿/소트 리더십도 순위·전환·브랜드 측면에서는
여전히 제 몫을 함 — 포맷마다 기대하는 역할을 다르게 판단하세요.

## 콘텐츠 필러와 토픽 클러스터

콘텐츠 필러는 브랜드가 소유할 3-5개 핵심 주제입니다. 각 필러가 관련 콘텐츠 클러스터를 만듭니다.
대부분은 `/blog` 아래 좋은 내부 링크만으로 충분하며, 여러 층위의 깊이를 가진 포괄적 리소스를
만들 때만 `/guides/topic` 같은 전용 URL 구조가 필요합니다.

**필러 식별 방법**: 제품 주도(제품이 해결하는 문제) / 오디언스 주도(ICP가 배워야 할 것) / 검색 주도
(업계에서 검색량 있는 주제) / 경쟁사 주도(경쟁사가 순위권인 주제)

**좋은 필러 기준**: 제품/서비스와 정렬, 오디언스 관심사와 일치, 검색량/소셜 관심 존재, 여러 서브토픽을
담을 만큼 넓음

## 구매 여정 단계별 키워드 리서치

- **인지(Awareness)**: "what is", "how to", "guide to", "introduction to"
- **고려(Consideration)**: "best", "top", "vs", "alternatives", "comparison"
- **결정(Decision)**: "pricing", "reviews", "demo", "trial", "buy"
- **실행(Implementation)**: "templates", "examples", "tutorial", "how to use", "setup"

## 콘텐츠 아이디어 소스

1. **키워드 데이터** (Ahrefs/SEMrush/GSC 추출본): 토픽 클러스터, 구매 단계, 검색 의도, 빠른 성과
   기회(낮은 경쟁 + 적당한 볼륨 + 높은 관련성), 콘텐츠 갭 분석. 표: 키워드 | 볼륨 | 난이도 | 구매단계 |
   콘텐츠유형 | 우선순위
2. **통화/세일즈 콜 스크립트**: 질문→FAQ/블로그, 고통점→고객 언어로, 반론→선제적으로 다룰 콘텐츠,
   언어 패턴→고객의 정확한 표현, 경쟁사 언급→비교 대상
3. **설문 응답**: 주관식 응답의 주제/언어, 공통 테마(30%+ 언급 시 고우선순위), 리소스 요청, 포맷 선호
4. **포럼 리서치** (웹서치 활용): Reddit(`site:reddit.com [토픽]`), Quora(`site:quora.com [토픽]`),
   Indie Hackers/Hacker News/Product Hunt 등에서 FAQ, 오해, 논쟁, 용어 추출
5. **경쟁사 분석** (웹서치 활용): `site:competitor.com/blog`로 콘텐츠 찾기, 성과 좋은 글/반복 주제/
   공백/케이스 스터디/구조 분석 → 더 잘 다룰 수 있는 주제, 놓친 앵글, 개선할 outdated 콘텐츠 도출
6. **세일즈/서포트 인풋**: 반복 반론, 반복 질문, 지원 티켓 패턴, 성공 사례, 기능 요청과 근본 문제

## 아이디어 우선순위화

네 가지 요소로 점수화 (1-10점 × 가중치):
- 고객 임팩트 (40%) — 리서치에 얼마나 자주 등장했나, 얼마나 많은 고객이 겪나, 감정적으로 얼마나
  강한가, LTV 잠재력
- 콘텐츠-마켓 핏 (30%) — 제품이 해결하는 문제와 정렬되는가, 독점 인사이트가 있는가, 뒷받침할
  고객 스토리가 있는가, 자연스럽게 제품 관심으로 이어지는가
- 검색 잠재력 (20%) — 월 검색량, 경쟁 강도, 롱테일 기회, 검색 관심 추세
- 리소스 요구량 (10%) — 권위 있게 만들 전문성이 있는가, 추가 리서치 필요량, 필요한 에셋(그래픽/데이터)

점수를 매겨 순위를 매기고, 최고점 순서로 제작하세요.

## 캘린더 배분: 60/30/10

- **60% 검색가능** — 예측 가능한 수요를 잡는 기반 (유스케이스, 허브/스포크, 하우투)
- **30% 공유가능** — 소트 리더십, 자체 데이터, 오피니언. 수요를 만들고 링크/멘션을 얻음
- **10% 실험적** — 새로운 포맷/채널/베팅. 정체를 막는 저비용 보험

이는 시작 비율이지 규칙이 아닙니다. 신규 블로그는 검색가능 비중을 더 높이고, 카테고리 리더를
노리는 브랜드는 공유가능 비중을 더 높일 수 있습니다.

## 포맷별 제작 기준

- **블로그 글**: 초안 전에 **제목 후보 10개**를 먼저 뽑기(제목이 성과의 대부분을 좌우). 약 5회의
  편집 패스(구조/명확성/근거/문장/헤드라인·SEO) 계획
- **롱폼 가이드**: 필러의 플래그십. 목차와 스포크로의 내부 링크를 갖춘 포괄적 자료. 허브를 먼저
  만들고 스포크로 확장
- **영상**: 훅을 먼저 스크립트화, 페이오프를 앞에 배치, 제작 시점에 숏폼 클립으로 재가공할 것을
  염두에 둠
- **팟캐스트**: 인터뷰 하나에서 트랜스크립트, 인용 그래픽, 짧은 클립, 요약 글까지 뽑아냄. 에피소드
  설계 단계부터 이를 염두에 둘 것
- **이메일**: 발송당 하나의 아이디어, 제목이 곧 타이틀 — 여러 개 써보고 고르기

## 한 번 만들고 두 번 배포하기 (Create Once, Distribute Twice)

콘텐츠 제작은 절반의 일이고 배포가 나머지 절반입니다. 핵심: **하나의 뛰어난 콘텐츠를 모든 채널에
맞게 재가공**하는 것이 플랫폼마다 새 콘텐츠를 만드는 것보다 낫습니다. 만들 때부터 배포 훅을
내장하세요 — 독립적으로 소셜 포스트가 될 수 있는 소제목, 모듈처럼 발췌 가능한 섹션 구조, 미리
그래픽화할 인용구/통계.

**ORB 프레임워크 (퍼널로서)**: 빌린 것(Borrowed, 팟캐스트/게스트포스트/파트너십 — 발견) → 빌려 쓰는
것(Rented, 소셜/광고 플랫폼 — 참여, 단 알고리즘/오디언스를 소유하지 못함) → 소유한 것(Owned, 이메일
리스트/블로그/커뮤니티 — 전환, 유일하게 지속 가능한 자산). 상류의 모든 것은 결국 owned로 흘러야 합니다.

**피해야 할 실패 패턴**:
- **스프레이 앤 프레이**: 플래그십과 재가공 계획 없이 여기저기 뿌리기만 하면 효과가 쌓이지 않음
- **플랫폼 의존**: 빌린 땅 위에 짓기. 페이스북 오가닉 도달률은 ~20%에서 2% 미만으로 떨어짐 — 빌린
  채널은 언제든 조여질 수 있음
- **소유권 역설**: 팀들이 노력의 ~90%를 통제할 수 없는 채널(rented/borrowed)에 쓰고 실제로 전환을
  만들고 뺏길 수 없는 owned 자산을 방치함

## 산출물 포맷

콘텐츠 전략을 만들 때 다음을 포함해 제시하세요:

1. **콘텐츠 필러**: 근거와 함께 3-5개 필러, 각 필러의 서브토픽 클러스터, 제품과의 연결점
2. **우선순위 토픽**: 각 추천 콘텐츠별로 — 주제/제목, 검색가능/공유가능/둘다, 콘텐츠 유형, 타겟
   키워드와 구매 단계, 이 주제를 고른 이유(고객 리서치 근거)
3. **토픽 클러스터 맵**: 콘텐츠 간 연결 구조

## 관련 영역

- 개별 콘텐츠 작성 → `copywriting` 스킬
- SEO 기술 감사, 이메일 기반 콘텐츠, 소셜 콘텐츠는 이 스킬 원칙을 준용해 대응 (소셜은 `social` 스킬 참고)
