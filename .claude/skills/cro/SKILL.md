# CRO (Conversion Rate Optimization, 전환율 최적화)

마케팅 페이지나 폼(홈페이지, 랜딩페이지, 가격 페이지, 기능 페이지, 리드 캡처/문의 폼)의 전환율을
분석하고 개선안을 제시할 때 적용합니다. URL만 주어져도 이 프레임워크로 피드백할 수 있습니다.

## 초기 파악 사항

1. **페이지 유형**: 홈페이지/랜딩페이지/가격/기능/블로그/소개/기타
2. **주요 전환 목표**: 가입, 데모 요청, 구매, 구독, 다운로드, 영업 문의
3. **트래픽 맥락**: 방문자가 어디서 오는가? (오가닉/유료/이메일/소셜)

## 분석 프레임워크 (임팩트가 큰 순서)

### 1. 가치제안 명확성 (가장 임팩트 큼)
- 방문자가 5초 안에 "이게 뭐고 왜 나에게 중요한지" 이해할 수 있는가?
- 핵심 혜택이 명확하고 구체적이며 차별화되어 있는가?
- 고객 언어로 쓰여 있는가(회사 용어가 아니라)?
- **흔한 문제**: 기능 중심으로 쓰여 혜택이 안 보임 / 너무 모호하거나 너무 영리해서 명확성을 희생함 /
  가장 중요한 하나 대신 모든 것을 말하려 함

### 2. 헤드라인 효과
- 핵심 가치제안을 전달하는가? 의미 있을 만큼 구체적인가? 트래픽 소스의 메시지와 일치하는가?
- **강한 패턴**: 결과 중심("{고통 없이} {원하는 결과}를 얻으세요") / 구체성(숫자·기간·디테일 포함) /
  소셜 프루프("1만 개 이상의 팀이 함께합니다")

### 3. CTA 배치, 카피, 위계
- 명확한 하나의 주요 행동이 있는가? 스크롤 없이 보이는가? 버튼 텍스트가 행동이 아니라 가치를
  전달하는가? (약함: "Submit", "Sign Up", "Learn More" / 강함: "Start Free Trial", "Get My Report",
  "See Pricing")
- 주요 CTA와 보조 CTA의 논리적 위계가 있는가? 핵심 의사결정 지점마다 CTA가 반복되는가?

### 4. 시각적 위계와 스캔 용이성
- 훑어봐도 핵심 메시지가 전달되는가? 가장 중요한 요소가 시각적으로 두드러지는가? 여백이 충분한가?
  이미지가 메시지를 돕는가, 방해하는가?

### 5. 신뢰 신호와 소셜 프루프
- 유형: 인지도 있는 고객 로고, (구체적이고 출처가 명확하며 사진이 있는) 후기, 실제 숫자가 있는
  케이스 스터디 발췌, 리뷰 점수/개수, 보안 배지
- **배치**: CTA 근처, 혜택 주장 직후

### 6. 반론 처리
- 흔한 반론: 가격/가치 우려, "내 상황에도 통할까?", 도입 난이도, "안 되면 어떡하지?"
- **대응 수단**: FAQ 섹션, 보증, 비교 콘텐츠, 프로세스 투명성

### 7. 마찰점
- 너무 많은 폼 필드, 불명확한 다음 단계, 헷갈리는 내비게이션, 불필요한데 필수인 정보, 모바일
  경험 문제, 느린 로딩 시간

## 산출물 포맷

다음 구조로 제시하세요:

- **Quick Wins (지금 바로 적용 가능)**: 즉각적인 임팩트가 예상되는 쉬운 변경
- **High-Impact Changes (우선순위)**: 노력이 더 들지만 전환율을 크게 개선할 큰 변경
- **Test Ideas**: 단정하기보다 A/B 테스트로 검증할 가치가 있는 가설
- **Copy Alternatives**: 헤드라인/CTA 등 핵심 요소는 2-3개 대안과 근거

## 페이지별 프레임워크

- **홈페이지 CRO**: 차가운 방문자를 위한 명확한 포지셔닝, 가장 흔한 전환까지 빠른 경로, "구매 준비됨"과
  "아직 리서치 중" 둘 다 대응
- **랜딩페이지 CRO**: 트래픽 소스와 메시지 매치, 단일 CTA(가능하면 내비게이션 제거), 한 페이지에서
  논지 완결
- **가격 페이지 CRO**: 명확한 플랜 비교, 추천 플랜 표시, "어떤 플랜이 맞나" 불안 해소
- **기능 페이지 CRO**: 기능을 혜택에 연결, 사용 사례/예시, 체험/구매로 가는 명확한 경로
- **블로그 포스트 CRO**: 콘텐츠 주제와 맞는 맥락적 CTA, 자연스러운 지점에 인라인 CTA

## 실험 아이디어

추천 실험 시 고려할 영역: 히어로 섹션(헤드라인/이미지/CTA), 신뢰 신호와 소셜 프루프 배치, 가격
표시 방식, 폼 최적화, 내비게이션과 UX

## 폼 최적화 요지

필드 수를 꼭 필요한 만큼만 유지, 멀티스텝 폼은 진행 표시와 함께, 에러 메시지는 무엇이 잘못됐고
어떻게 고치는지 구체적으로, 불필요한 필수 필드(전화번호 등)는 선택으로 전환 고려.

## 관련 영역

- 가입/등록 프로세스 자체의 문제 → 일반 CRO 원칙을 가입 플로우에 적용해 대응
- 페이지 전체를 다시 써야 한다면 → `copywriting` 스킬
- 테스트로 검증하고 싶다면 → `ab-testing` 스킬
