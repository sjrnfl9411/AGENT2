# 소셜 콘텐츠 (Social Content)

LinkedIn, Twitter/X, Instagram, TikTok, Facebook 등 소셜 미디어 콘텐츠 제작·스케줄링·최적화,
콘텐츠 리퍼포징, 숏폼 비디오 스크립팅, 소셜 리스닝에 적용합니다.

## 제작 전 파악할 것

1. **목표**: 브랜드 인지/리드/트래픽/커뮤니티 중 무엇? 사람들이 어떤 행동을 하길 원하는가?
   퍼스널 브랜드/회사 브랜드/둘 다?
2. **오디언스**: 누구에게 도달하려 하는가? 어떤 플랫폼에 가장 활발한가? 어떤 콘텐츠에 반응하는가?
3. **브랜드 보이스**: 톤(전문적/캐주얼/위트있는/권위적)? 피해야 할 주제? 특정 용어/스타일 가이드?
4. **리소스**: 소셜에 쓸 수 있는 시간? 리퍼포징할 기존 콘텐츠? 영상 제작 가능 여부?

## 플랫폼 빠른 참조

| 플랫폼 | 강점 | 빈도 | 핵심 포맷 |
|---|---|---|---|
| LinkedIn | B2B, 소트 리더십 | 주 3-5회 | 캐러셀, 스토리 |
| Twitter/X | 테크, 실시간, 커뮤니티 | 일 3-10회 | 스레드, 핫테이크 |
| Instagram | 비주얼 브랜드, 라이프스타일 | 일 1-2 포스트+스토리 | 릴스, 캐러셀 |
| TikTok | 브랜드 인지, 젊은 오디언스 | 일 1-4회 | 숏폼 비디오 |
| Facebook | 커뮤니티, 로컬 비즈니스 | 일 1-2회 | 그룹, 네이티브 비디오 |

## 콘텐츠 필러 프레임워크

전문성과 오디언스 관심사에 맞는 3-5개 필러를 중심으로 구성. (예: SaaS 창업자라면 업계 인사이트
30% / 비하인드 스토리 25% / 교육 25% / 개인 15% / 프로모션 5%)

필러별로 물을 것: 어떤 독특한 관점이 있는가? 오디언스가 무엇을 묻는가? 과거 무엇이 잘 됐는가?
무엇을 꾸준히 만들 수 있는가? 비즈니스 목표와 맞는가?

## 훅 공식

첫 줄이 나머지를 읽을지 결정합니다.

- **호기심형**: "나는 [통념]에 대해 틀렸었다.", "[결과]가 일어나는 진짜 이유는 생각과 다르다."
- **스토리형**: "지난주 [예상 밖의 일]이 있었다.", "3년 전 나는 [과거 상태]였다. 오늘은 [현재 상태]."
- **가치형**: "[흔한 고통] 없이 [원하는 결과]를 얻는 법", "[숫자]가지 [결과]를 만드는 것들"
- **반골형**: "비인기 의견: [대담한 주장]", "[통념]은 틀렸다. 이유는:"

## 콘텐츠 리퍼포징 시스템

가장 좋은 소셜 콘텐츠는 처음부터 만드는 게 아니라 롱폼 필러 콘텐츠에서 추출해 각 플랫폼에
맞게 각색한 것입니다.

**블로그 → 소셜**: LinkedIn(핵심 인사이트+댓글에 링크, 요점 캐러셀), Twitter/X(핵심 요약 스레드),
Instagram(비주얼 캐러셀, 요약 릴스)

**팟캐스트/영상 → 소셜**: "콘텐츠 원자"(단독으로도 성립하는 순간)를 추출 — 인용가능한 순간(15-60초),
스토리 아크(60-90초), 실전 팁(30-60초), 논쟁적 주장, 데이터/통계 콜아웃, 비하인드 신. 워크플로우:
트랜스크립트 확보 → 좋은 순간 타임스탬프 표시 → 클립 추출 → 단독으로 이해되는 캡션 작성 → 자막
추가(무음 시청 다수) → 1-2주에 걸쳐 스케줄. 에피소드당 목표: 숏폼 클립 3-5개, LinkedIn 포스트
1-2개, 트위터 스레드 1개, 캐러셀 1개, 뉴스레터/블로그 섹션 1개

**웨비나/라이브 → 소셜**: 핵심 슬라이드+코멘터리(캐러셀), Q&A 하이라이트(스레드), 발표자 인용
(그래픽), 청중 반응/투표 결과(참여 포스트), 전체 녹화(짧은 클립)

**뉴스레터 → 소셜**: 핵심 인사이트(LinkedIn 포스트), 큐레이션 링크+코멘터리(스레드), 데이터/통계
(인용 그래픽), 핫테이크(트윗/LinkedIn)

**리퍼포징 워크플로우**: 필러 콘텐츠 제작 → 콘텐츠 원자 추출(개당 5-10개) → 플랫폼별 각색(포맷/
길이/톤) → 단독 캡션 작성 → 주간 분산 스케줄 → 에버그린은 3-6개월마다 재활용

## 콘텐츠 캘린더 & 배칭

주간 계획표로 요일×플랫폼을 매핑. 배칭 전략(주 2-3시간): 필러 주제 리뷰 → LinkedIn 5개 작성 →
트위터 스레드 3개+데일리 트윗 → Instagram 캐러셀+릴스 아이디어 → 전체 스케줄 → 실시간 참여를
위한 여지 남기기

## 참여(Engagement) 전략

**일일 루틴(30분)**: 내 포스트 댓글 전부 응답(5분) → 타겟 계정 포스트 5-10개에 댓글(15분) →
인사이트 추가해 공유/리포스트(5분) → 신규 커넥션에 DM 2-3개(5분)

**좋은 댓글**: 새 인사이트 추가(단순 "좋아요"가 아니라), 관련 경험 공유, 사려 깊은 후속 질문,
뉘앙스 있게 정중히 반박

## 분석 & 최적화

**측정 지표**: 인지도(노출, 도달, 팔로워 성장률) / 참여(참여율, 댓글[좋아요보다 가치 높음], 공유,
저장) / 전환(링크 클릭, 프로필 방문, DM, 리드 귀속)

**주간 리뷰**: 상위 3개 포스트(왜 잘됐는지), 하위 3개(무엇을 배울지), 팔로워 성장 추세, 참여율 추세,
최적 게시 시간

**참여가 낮으면**: 새 훅 테스트, 다른 시간대, 다른 포맷, 타인과의 참여 늘리기
**도달이 줄면**: 포스트 본문 외부 링크 피하기, 게시 빈도 증가, 댓글 참여 늘리기, 영상/비주얼 테스트

## 숏폼 비디오 (TikTok, Reels, Shorts)

**플랫폼 스펙**: TikTok(15-60초, 9:16, 트렌딩 사운드/날것 느낌) / Reels(15-30초, 9:16, 정제된
콘텐츠, 저장·공유 우대) / Shorts(30-60초, 9:16, 유튜브 SEO 적용, 검색 가능한 제목)

**3초 법칙**: 스크롤을 멈추게 할 3초. [비주얼 훅] + [보이스 훅] + [텍스트 오버레이]가 첫 1초에
동시에 터져야 함

**구조 예시**:
- 문제-해결(15-30초): 훅(0-3s, 문제 제시) → 심화(3-10s, 왜 중요한지) → 해결(10-25s, 방법/제품/팁) →
  CTA(25-30s)
- 리스트형(30-60초): 훅(0-3s) → 항목들(3-50s, 5-8초마다 하나) → CTA(50-60s)
- 튜토리얼(30-60초): 훅(0-3s, 결과 먼저 보여주기) → 개요(3-8s) → 단계(8-50s) → 결과+CTA(50-60s)

**자막**: 무음 시청이 많아 자막이 시청 지속시간을 25-40% 늘림. 최대 2줄, 줄당 3-5단어, 굵은
산세리프+검정 외곽선, 핵심 단어 강조색

**흔한 실수**: 느린 훅, 텍스트 오버레이 없음, 나쁜 오디오, 너무 김, CTA 없음, 댓글 방치(첫 1시간이
중요)

## 관련 영역
